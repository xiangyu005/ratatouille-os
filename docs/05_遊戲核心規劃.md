## 1. 遊戲整體定位

本專案正式名稱為「鼠於我的小餐館」，專案資料夾名稱為 `ratatouille-os`，是一款結合**家庭生活、餐廳經營、自由探索、自動化與深度管理**的開放式模擬遊戲。故事、角色、美術與世界觀由團隊原創，料理鼠王元素保留為彩蛋致敬，不直接以原作劇情及角色作為主要內容。

玩家扮演一隻經營餐廳的老鼠，可以自由安排上班、下班、回家、料理、採購、休息及其他日常活動。

遊戲不設定固定通關目標，也不要求玩家持續擴張。玩家可以享受日常生活、探索料理與食材、改善家庭條件、經營餐廳，或深入研究工作安排與資源管理，提高經營效率。

遊戲表層提供直覺的生活體驗；當玩家希望深入理解機制時，可以接觸 OS 演算法、料理製作、食材營養與食品安全等專業知識。

### 1.1 核心設計理念

**自由體驗生活，透過經營改善生活；自動化解放操作，專業知識創造更深層的可能性。**

我們希望玩家可以自行決定要投入多少時間在餐廳、家庭、探索或管理上，而不是被固定任務與成長路線限制。

---

### 1.2 原創內容與彩蛋邊界

原創世界觀與正式美術分別由 `07`、`04` 承接，角色、故事及彩蛋細節仍待設計。彩蛋內容與對外展示方式確定時，需確認尚待處理的著作權與授權事項。

## 2. 六個核心遊玩面向

### 2.1 生活：體驗自由的餐飲日常

玩家可以上班、下班、回家休息、料理、購物及照顧家人，依照自己的想法安排一天。

家庭生活不只是維持餐廳經營的附屬功能，而是遊戲本身的重要體驗。

玩家能夠利用經營收入改善家庭環境與生活條件，逐漸取得更便利的生活方式。

### 2.2 經營：讓收入改善生活

玩家透過餐廳販售餐點取得收入，並自行決定如何運用資金。

資金可以用於餐廳設備、廚具、食材、菜單、工作能力，以及家庭生活的改善。

升級不只是增加數值，更重要的是讓玩家取得新的能力、改變既有條件，或減少原本需要親自完成的工作。

餐廳與家庭的投資方向應具有選擇空間，不要求所有玩家使用同一條最佳升級路線。

### 2.3 自動化：讓玩家逐漸獲得自由時間

餐廳原本需要主角手動參與的工作，應逐漸具備由家族員工或自動化系統接管的能力。

即使取得完整自動化，玩家仍然可以選擇親自參與料理與經營。

**完整流程自動化不代表永遠不中斷。** 家族員工仍受到營養、休息及其他工作狀態限制。

遊戲後續可以透過機器老鼠，讓餐廳逐漸具備 24 小時自動營運的能力。

### 2.4 效率：讓管理方式真正影響成果

玩家可以調整員工負責哪些工作、使用哪些設備，以及採用什麼工作管理策略。

不同安排應能在實際運作中產生差異，例如工作等待、設備閒置、顧客排隊或餐盤堆積。

OS 演算法應自然應用於這些工作與資源管理問題，而不是直接給玩家一個抽象的效率倍率。

深入研究管理策略可以提高效率，但**不應成為正常遊玩所必須具備的能力**。

### 2.5 探索：讓玩家對既有生活世界保持好奇

探索不一定需要大型地圖或大量新場景。

目前優先以家庭、餐廳、小鎮與既有商店為中心，透過料理、食材、商品、設備、知識與生活變化提供探索內容。

玩家可以主動了解尚未使用過的食材、料理知識或新的經營可能性。

額外地點、特殊人物互動及獨立探索功能，則視開發餘力再規劃。

### 2.6 知識：直覺的表層玩法，深入的專業內容

玩家不需要理解 OS 演算法、營養學或食品安全法規，也應能正常遊玩。

但有興趣的玩家，可以透過遊戲中的資訊與相關功能，深入理解料理、食材、營養、工作排程及資源管理。

其中家庭料理將結合餐點知識庫與 AI 營養師，根據現有食材和營養需求提供料理建議。

遊戲教學的目標是讓玩家知道如何遊玩，不應強制將 OS 演算法課程塞進日常操作中。

## 3. 玩家的日常循環與成長

### 3.1 自由安排一天

玩家可能經歷以下日常：

**上班 → 經營餐廳 → 下班 → 回家 → 休息**

但這只是常見的生活方式，不是固定或強制的遊戲流程。

玩家可以自由決定何時工作、何時採購、何時回家，以及如何分配經營和生活的時間。

遊戲以連續時間運作，既有時間設定為一個遊戲日約等於現實 20 分鐘，並可依睡眠與移動等情境進行時間跳轉。

### 3.2 餐廳的基本工作體驗

餐廳以一套固定的生產流程為基礎：

**進貨 → 儲藏 → 取食材 → 放到烹飪桌 → 自動做菜 → 送餐 → 收盤與洗碗**

其中進貨、儲藏屬於備貨管理；日常訂單則會要求玩家或員工取料、製作及送餐。收盤與洗碗另外產生工作負擔。

不論餐廳發展到什麼程度，主要工作架構都維持一致，但執行者、處理時間、設備條件及部分操作方式可能改變。

不同餐點也不需要建立完全不同的手動烹飪流程。

### 3.3 餐點、廚具與食材如何形成經營成長

餐廳目前規劃三種可以獨立解鎖的內容：

- **廚具：** 代表餐廳具備哪些烹飪方式與製作能力。
- **食材：** 代表餐廳可以取得哪些料理原料；購買後仍屬於會消耗的庫存。
- **菜單：** 代表餐廳掌握哪些可製作及販售的料理資訊。

三種解鎖方向沒有固定先後順序，但料理必須符合製作條件才能提供給客人點餐。

例如玩家已取得一道料理的菜單資訊，但還沒有必要廚具，顧客就不能點這道料理。

廚具的主要作用是開放製作能力，而不是為每一種廚具建立額外的烹飪小遊戲。

### 3.4 家庭料理與營養管理

家庭料理與餐廳販售菜單的定位不同。

餐廳食譜主要用於菜單解鎖及經營；家庭料理則著重自由選擇、料理知識與營養補充。

玩家可以利用家庭現有食材，透過餐點知識庫和 AI 營養師了解適合製作的料理，並協助家族成員維持營養。

家庭營養不只是資料展示，還會影響家族員工是否具有工作能力。

後續家庭升級可以改善營養補充及飲食安排的便利性，減少玩家反覆管理家庭飲食的負擔。

## 4. 遊戲如何產生成長與樂趣

我們希望玩家持續遊玩的原因，不只是等待賺錢和購買下一項升級，而是經營條件改變後，玩家會自然發現新的遊玩可能性。

### 4.1 第一次取得員工：從親自操作到嘗試分工

初期玩家主要親自處理餐廳工作。

當第一位家族員工加入時，玩家可以嘗試將部分工作交給員工，觀察他如何移動、使用設備及執行工作。

玩家可能反覆修改分工方式，觀察不同安排的結果。

這個階段希望帶來的是**第一次使用自動化能力的好奇心與實驗樂趣**。

因此員工的工作行為應該能被玩家觀察，而不是只在背景直接產生料理結果。

### 4.2 新菜單改變工作條件：原本的安排不一定永遠有效

假設原本一份料理從查看訂單、取料、製作到送餐，平均約需 15 秒。

當玩家解鎖新菜單後，部分料理的處理時間可能增加至 25 秒。

如果顧客到達速度超過目前的處理能力，可能開始排隊；若員工忙於其他工作，也可能造成餐盤堆積或其他工作等待。

玩家會發現：原本順利的工作安排，在條件變動後未必仍然適合。

此時玩家可以暫停遊戲、重新分配員工與設備，觀察結果後再繼續修正。

**我們希望管理問題是由遊戲條件自然產生，而不是刻意跳出一道 OS 演算法題目。**

同時，原本的配置即使效率較差，通常仍應能繼續營運，不強迫休閒玩家不斷最佳化。

### 4.3 全流程自動化：從經營工作轉向自由生活

當員工能夠接管所有必要工作後，玩家不必持續待在餐廳。

玩家可以回家料理、處理家庭生活、前往商店，或探索自己感興趣的知識與經營內容。

這是遊戲的重要體驗轉折：

**餐廳自動化的意義，不只是賺錢速度改變，而是玩家的時間重新變得自由。**

但由於員工仍有營養與休息需求，餐廳仍可能因員工狀態而中斷。

### 4.4 更複雜的管理：從可運作走向更有效率

隨著菜單、食材、廚具、設備及員工增加，玩家會面對更多互相影響的工作條件。

例如增加人力後，可能發現部分設備成為新的瓶頸；改善設備後，原本的工作配置又可能需要重新調整。

對進階玩家而言，這些變化提供持續研究、比較與改善的機會。

對休閒玩家而言，只要能正常經營，就不必追求最佳效率。

### 4.5 24 小時自動化：突破一般員工的生理限制

一般家族員工即使增加到較多人，也不能保證全天不中斷營運。

後續透過機器老鼠接管必要工作，讓餐廳逐漸具備 24 小時自動營運能力。

這是另一項重要經營能力的成長，但不代表遊戲結束，也不代表餐廳不再需要食材、管理或其他營運條件。

---

### 4.6 後期目標與動態成就的長期定位

AI 動態成就列為長期規劃，未來希望依玩家遊玩中的有趣情況自動頒發獎項。先完成必要功能，待其他玩法成熟後再研究，不影響現階段設計與工作安排，也不保證本次專題完成。

若未實作動態成就，玩家仍可追求完成所有既定升級，持續經營並挑戰長期客源及經營能力。這是可自選的後期目標，不新增固定結束天數或強制通關，也不代表目前候選升級全數定案。既有生活、探索與自由最佳化的價值維持不變。

## 5. 遊戲規模與正常遊玩時間

### 5.1 規模定位

本專案希望完成的是：

**一款內容與系統都有一定豐富度、能讓玩家感受到小型生活世界的開放式經營遊戲。**

主要深化既有場景與玩法，不以大量新增地圖或獨立小遊戲填充內容。

### 5.2 正常遊玩的時間指標

以下是用於遊戲規模與經濟平衡的初步目標，不是固定章節、強制任務或解鎖時間。

| 正常遊玩累計時間 | 主要經營能力 |
|---|---|
| **約 30 分鐘** | 熟悉基本遊玩方式，取得第一位家族員工 |
| **約 90 分鐘** | 預估以約三位員工實現餐廳完整流程自動化 |
| **約 180 分鐘** | 取得透過機器老鼠支援 24 小時自動營運的能力 |
| **180 分鐘後** | 持續生活、經營、探索與最佳化，沒有固定結局 |

第一位員工目前以約 20 份訂單的經營成果作為初步估算。

實際達成時間會因家庭支出、升級投資、管理策略與玩家的生活方式而不同。

遊玩時間除了手動操作，也包含玩家觀察員工、嘗試配置、查閱資訊及停下來思考的時間。員工安排期間預計允許暫停遊戲世界。

### 5.3 暫定內容規模

| 內容項目 | 規模基準 |
|---|---|
| 主要場景 | 家庭、餐廳、小鎮地圖及既有三類商店 |
| 餐廳菜色 | 12 道，分三階段解鎖 |
| 烹飪廚具 | 約 4 種 |
| 儲藏類型 | 3 種 |
| 不同食材 | 約 24～30 種 |
| 家庭料理知識庫 | 暫估約 200 道料理資料 |
| 家族角色 | 既有最多五隻老鼠的規模，主角與員工計數方式待確認 |
| 家庭功能升級 | 候選約 4～5 項 |
| 家庭外觀變化 | 候選約 3～5 項 |
| 餐廳既有設備升級 | 候選約 4～6 項 |
| 機器老鼠 | 暫以一種基本工作型態為候選，配置數量待驗證 |

這些數量用來傳達預期內容規模，而不是最終物件清單。

其中家庭與設備升級、機器老鼠類型等仍屬於初步估算，尚未確認是否全部採用。

### 5.4 規模控制原則

優先透過既有系統的變化增加遊戲深度。

例如增加新菜單，可以帶來新的食材需求與工作負荷；增加廚具，可以開放新的料理類型；改善儲藏設備，可以改變食材保存與採購條件。

不為每一道料理建立獨立小遊戲，也不為了增加遊玩時間而任意加入複雜社交、情緒或大型開放世界系統。

## 6. 共同的遊戲設計原則

### 6.1 玩家必須能感受到行為的回饋

玩家的投資與選擇應在遊戲中具有可感知的結果。

例如家具、設備、家庭環境、餐廳能力或經營狀態發生變化。

具體呈現方式仍需後續設計，但不能讓所有成長都只有數值增加。

### 6.2 選擇與取捨必須有意義

餐廳收入可以用於家庭或餐廳，玩家應能依照自己的目標安排投資方向。

不同選擇可以影響經營效率、生活便利性與能力取得速度，但不應只有一條唯一正確的升級路線。

### 6.3 允許經營失敗，但保留恢復能力

玩家可能因成本、庫存、員工營養或工作安排而遇到經營困難。

但遊戲不應產生無法恢復的存檔狀態。

主角應能作為必要時的手動工作後備；若家庭失去食材與購買能力，則需要有限制的基本食材援助，讓玩家恢復營養並重新經營。

這類援助的具體條件與防止濫用方式，留待後續規劃。

### 6.4 複雜機制可以深入，但不強迫所有玩家掌握

遊戲可以具有真正的 OS 排程與資源管理深度，但一般玩家應能透過預設安排正常遊玩。

管理策略改善的是效率與經營結果，不應變成維持基本遊玩資格的必要條件。

教學應以操作與生活體驗為主，進階知識讓玩家自行探索與查閱。

### 6.5 成長應產生新可能性，而不只是等待時間增加

重要升級應帶來能力、便利性、可見變化或新的經營選擇。

尤其新菜單、廚具與員工配置的加入，應有機會改變原本的經營條件，讓玩家重新觀察與思考。

但是重新調整應該是改善經營的機會，而不是每次升級後都強迫玩家解決故障。

### 6.6 開放式遊玩不代表缺乏成長

遊戲沒有固定結局，也不要求玩家依照特定順序遊玩。

玩家可以投入家庭、餐廳、料理知識或效率研究，並以自己的方式持續經營。

正常遊玩三小時的時間指標，是為了估算內容及能力成長節奏，不是限制玩家的遊玩選擇。

## 7. 仍需由組員進一步規劃與驗證的方向

目前的遊戲核心與目標規模已具有初步輪廓，但詳細系統不應由這份文件直接定案。

後續需要特別注意：

1. **世界與角色運作：** 時間、移動、工作狀態、員工行為及暫停時的處理方式。
2. **餐廳工作：** 固定流程下如何分派工作、使用設備、處理等待及比較效率；加入評論隱性影響客源，以及未收餐盤、環境衛生、蒼蠅與進店後離開的行為設計，具體數值仍未定。
3. **經濟與成長：** 收入、成本、資金投入如何使正常玩家逐步取得主要經營能力。
4. **家庭生活：** 營養補充、自由料理、知識庫與家庭便利功能如何銜接。
5. **廚具、食材與菜單：** 在沒有固定解鎖順序的前提下，如何提供清楚的製作條件與經營選擇。
6. **商店與儲藏：** 食材開放方式、不同儲藏類型、庫存與採購規則。
7. **自動化與機器老鼠：** 約三位員工能否完成全流程自動化，以及機器老鼠如何支援 24 小時運作。
8. **OS 與課堂要求：** 確保實際機制能承接演算法、Skill、MCP、AI 與知識庫需求，並能被操作與驗證。

以上問題是後續設計的方向，不代表需要在本文件內直接完成答案。

## 8. 遊戲核心總結

我們希望製作的不是一款要求玩家不斷完成任務、購買升級的線性餐廳遊戲，也不是將 OS 演算法包裝成料理題目的教學系統。

而是一個玩家能真正體驗日常生活、經營餐廳與改善家庭的小型世界。

玩家從親自料理開始，逐漸發現家族員工、自動化與管理策略的可能性。當菜單、食材、廚具或人力改變時，餐廳會以實際運作結果回應玩家的安排，讓有興趣的人能繼續研究更好的方法。

當工作逐漸由系統接管，玩家則能將更多時間留給家庭、探索與自己喜歡的活動。

**我們真正希望實現的遊戲目標，是讓玩家透過經營獲得選擇生活方式的自由，並讓願意深入研究的人，從同一套遊戲中發現更深的管理與專業知識。**
