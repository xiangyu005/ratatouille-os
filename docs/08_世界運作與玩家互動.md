# 08｜世界運作與玩家互動

**版本：V0.4｜遊戲設計規格稿｜未決事項保留，尚未進行原型驗證**

## 一、設計目標與適用範圍

本組文件定義世界時間、角色工作、場景外活動、空間互動及保存恢復的共通規則，支援玩家在家庭、餐廳與商店之間自由安排生活。玩家僅直接控制主角，家族員工依安排工作；自動化逐步釋放玩家時間，同時保留親自參與經營的選擇。

世界運作須維持以下要求：

1. 主角離場後，已安排的活動仍依條件持續執行。
2. 睡眠與旅行跳時須結算期間的工作、資源消耗及事件。
3. 場景切換與保存恢復須延續狀態，不得重複結算已完成事件。
4. 管理操作期間須暫停全世界，供玩家調整配置。

家庭料理、餐廳訂單與商店供應的領域規則，由各自文件定義；本組文件不另行決定其數值或實作架構。

正文以「須／應」表達要求、「可」表達允許行為、「不得」表達限制。候選、待協調與待驗證的狀態依各條文標示；已選定方案不等於已通過驗證。情境與範例僅解釋規則，不增加數值或功能要求。

## 二、共通設計原則

### 2.1 統一時間與狀態延續

全場景使用同一世界時間，正常流速為 **24 遊戲小時對應 20 現實分鐘**。正常活動持續推進，暫停停止全世界活動，跳時則快速結算至目標時刻。主角切換地點不停止其他場景的工作，也不重置資源或進度。

### 2.2 玩家配置權與工作延續

員工只能執行玩家授權的工作，不得因等待而擅自改派職責。玩家可親自參與或重新配置，變更影響後續安排，不撤銷已完成結果或搶占既有執行權。

管理效果應來自移動成本、設備等待及工作銜接等實際差異。室內設備與家具位置固定，玩家不透過重新擺設縮短路線。

### 2.3 即時模擬與背景模擬一致

即時場景須呈現角色移動、等待與工作；背景運作可省略畫面，仍須遵守相同時間成本、資源消耗與限制。

例如一段營業時間可能包含生產、缺料等待與補貨後復工，不能以單一效率倍率取代全部結算。效率資訊用於比較配置，成果仍由工作與事件形成。

### 2.4 經營限制與恢復能力

完整自動化不保證營運不中斷。老鼠員工受營養與休息限制，機器老鼠仍受食材、設備及可執行工作等條件影響。

即使經營失敗，主角仍須能回家，透過有限的基本食材援助、基礎料理與手動工作恢復。共通規則須支援此路徑，避免永久無法繼續的狀態；援助條件與數值由 09～12 定義。

## 三、主要操作流程

以下情境以角色具備工作能力、相關活動已開放為前提，說明機制銜接，不指定每日行程或起始場景。

### 3.1 手動參與工作

主角進入設備的互動範圍能與設施互動，並向系統提出工作請求，當符合條件且系統核發執行權後，進入操作確認等待。確認期間不能移動、可取消；確認完成後正式執行，不得任意中斷。介面須區分兩個階段。

當互動事件發生在同一Tick時即為競爭，發生競爭時主角優先，其他角色依玩家設定順序分配。已有執行者的工作不得被取代；未取得工作的員工重新檢查其他授權工作，全部不可執行時等待並持續檢查可執行的工作。此規則使手動參與與自動化能共同運作，避免重複取得或完成工作。

### 3.2 管理與配置

玩家可在觀察到員工等待或設備使用上負荷過高後，進入管理操作調整安排。此時全世界暫停，工作、營養與背景事件均不推進，讓玩家能比較配置而不承受思考期間的消耗。

恢復後，玩家觀察新配置的效果。其餘遊戲面板是否適用管理暫停，仍由 08／13 逐一確認。

### 3.3 場景移動與背景運作

以主角未執行工作且符合離場條件的情境為例：主角前往出口開啟主地圖，選定目的地並確認旅行；系統結算旅程時間，原場景改由背景模擬接續。

背景工作仍包含移動、操作確認與正式執行成本，缺料仍會造成等待。返回時呈現抵達當下的狀態，不重演已完成事件或重播其過場動畫，未完成工作則接續目前進度。

正式執行工作時能否離場仍未定；上述前提不構成一律禁止離場的規則。

### 3.4 睡眠與時間跳轉

主角睡眠時，系統結算期間的工作、資源與事件，推進至睡眠結束。生物家族員工也需要休息；機器老鼠可依原安排執行符合條件的工作。

當時間跳轉時。結束後可用簡短通知提示必要變化，不強制顯示完整結算報表。睡眠開始時，生物員工如何由確認或正式執行轉入休息，仍須與 09／11 協調，不預設立即中斷全部工作。

### 3.5 保存與退出

遊戲以自動保存為主、手動保存為輔。安全退出須先完成保存，下次啟動則接續最近有效且一致的進度。不提供玩家選擇歷史存檔回溯，也不補算關閉遊戲期間的離線經營。

## 五、設計狀態與驗證要求

目前選定的方案以交接資料為依據，數值平衡、跨領域細則及工程可行性仍須逐項驗證。

20 Tick/s 為世界更新頻率候選，正常流速下 0.5 現實秒為操作確認時間候選，60 FPS 為畫面測試目標。工作耗時須以時間長度定義，不因更新頻率改變而縮短或延長。

室內比例與操作參數尚未定案。1 U 等於老鼠寬度、4 U／現實秒、1 U 互動半徑及先前家具尺寸均為候選或示意；起始餐廳僅為個人偏好。起始場景、時間、位置與資源仍待確認。

主要待協調事項包括工作途中營養不足、睡眠時工作交接、正式執行中離場，以及配送與補貨的適用階段，完整清單見附錄 B。

驗證須在相同條件下比較即時、背景與跳時結果，並測試工作競爭、確認取消、移動手感及保存恢復。遊玩與設計調整記入 [14](14_遊戲流程測試與調整紀錄.md)，功能、整合與效能證據記入 [24](24_系統測試與品質驗證紀錄.md)。目前尚無原型、遊玩或效能通過結果。
